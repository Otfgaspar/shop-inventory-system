

# Shop Inventory & Sales System

A web system for small shops. The owner records products and stock,
cashiers process sales and print receipts, and stock updates
automatically with low-stock warnings.

## Features (v1)
- Admin and cashier roles
- Product and stock management
- Sales with receipts
- Low-stock list and daily sales report

## Tech
PHP, MySQL, HTML/CSS

## Setup
1. Install XAMPP and start Apache and MySQL
2. Import `database/schema.sql` in phpMyAdmin
3. Copy `config/database.example.php` to `config/database.php`
4. Open http://localhost/shop-inventory-system
